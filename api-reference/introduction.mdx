## Creating an API Key

To begin using the RevRing API, you must first create an API Key from the dashboard.
API Keys are sensitive credentials, so ensure to store them securely and limit access.

<Card
  title="Create an API Key"

>
  Create a new API Key from the RevRing Dashboard
</Card>

### Full access or read-only

Each key has an access level, chosen when it is created:

- **Full access**: every endpoint, including creating agents, placing calls and deleting things.
- **Read-only**: reads only (`GET` endpoints and the batch lookups). Any request that would create, change or delete something is refused with `403 read_only_key`. Use read-only keys for reporting, dashboards and integrations that only need to read.

## Authentication

All API endpoints are authenticated using the `x-api-key` header:

```bash
curl --request GET \
  --url https://api.revring.ai/v1/agents \
  --header 'x-api-key: <api-key>'
```
