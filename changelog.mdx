## October 5, 2026

### Keep your webhook handler when you switch
Set `postCallWebhookFormat` to `retell` or `elevenlabs` and the post-call webhook arrives in that platform's payload shape, filled from the RevRing call record. The importer sets it automatically. [Guide](/platform/webhooks#compatibility-formats)

### Knowledge bases hold 50 sources
The limit per knowledge base is now 50 sources (was 10).

### Campaigns
Call a contact list with one agent. Contacts without a time zone are called in the local time of their number's area code, and `voicemailStrategy: "last_attempt"` leaves a voicemail only on the final attempt. Calling windows follow each contact's own time zone, retries happen automatically by outcome (no answer, busy, voicemail, declined, failed), new calls are paced to suit your carrier, numbers on your do-not-call list are never dialed, and a CSV export carries every contact's outcome with extraction and evaluation columns. Campaign calls carry `campaignId` on the call record and in the post-call webhook. [Guide](/platform/campaigns)

### Import agents from Retell AI and ElevenLabs
Bring existing voice agents over with your API key for the other platform. A dry run reports how every setting carries over (prompt, opening, variables, tools, transfers, voicemail, knowledge, post-call analysis) and what is left to you; importing creates the agents with their tools and knowledge bases, and importing again updates them. [Guide](/platform/importing-agents)

### End a live call from your server
`POST /v1/calls/{id}/end` hangs up a call in progress immediately; it is recorded as `API_ENDED` and still gets its recording, summary and post-call webhook. Use it when your own logic decides the call should stop. [Reference](/api-reference/calls/end)

### Concurrency headroom
`GET /v1/analytics/active` now also returns `concurrency` (`active`, `limit`, `available`), counted exactly like the check behind `concurrency_limit`, so dialers can pace calls instead of retrying. [Reference](/api-reference/analytics/active)

### Spoken text never reads a placeholder aloud
If an opening line, voicemail message, hold or intro message references a `{{variable}}` that has no value on a call, the placeholder is dropped and the sentence tidied ("Hi {{first_name}}, this is Maya" becomes "Hi, this is Maya") instead of being read out.

### Webhook signing
Every webhook RevRing sends (pre-call, post-call, message received) can now be signed. Create a secret with `POST /v1/webhooks/signing-secret` and verify the `X-RevRing-Signature` header on the raw body. Opt-in per organization; nothing changes until you create a secret. [Guide](/platform/webhooks#verify-webhook-sources)

### Webhook retries
A post-call webhook that fails (connection error, timeout, non-2xx) is retried 1, 5 and 30 minutes later. Handlers should be idempotent on the call `id`. The outcome is on the call record as `postCallWebhookStatus` and `postCallWebhookAttempts`. [Guide](/platform/webhooks#response-expectations)

### Test runs against a live version
Test runs use the saved draft by default. Pass `environment` (`production` or an environment name) on `POST /test-suites/{id}/runs` to test the version callers get. [Guide](/platform/versioning#testing-before-you-publish)

## October 4, 2026

### Drafts, publishing and environments
Agents can now be edited without going live. Switch an agent to manual publishing (`publishMode: "manual"`), edit the draft, test it, and publish when ready; earlier versions can be made live in one call. Named environments pin a version with their own variable defaults and can be bound to inbound numbers, the web widget and `POST /calls`. Every call record carries the version it ran on. [Guide](/platform/versioning)

### Post-call data extraction
Define typed fields per agent (`postCallExtraction`) and get them filled from each conversation on the call record and in the post-call webhook as `extraction`. [Guide](/platform/webhooks#post-call-data-extraction)

### Post-call evaluation
Write success criteria per agent (`postCallEvaluation`) and every call is judged pass, fail or unknown with a one-sentence reason. Pass rates per criterion are on the analytics overview and the dashboard. [Guide](/platform/webhooks#post-call-evaluation)

### SIP trunk address validation
A trunk's proxy must now be a hostname or IP that resolves. Typos such as a misspelled carrier domain are refused when the trunk is created instead of producing a trunk that can never place a call. [Reference](/api-reference/sip-trunks/create)

### Noise suppression for every agent
Background noise and other voices on the caller's side are suppressed before the agent listens. On by default for all agents; turn it off per agent with `noiseCancellation: "off"`.
